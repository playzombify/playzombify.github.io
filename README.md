# Zombify

A pixel zombie defense game. Scavenge by day, hold the shelter by night, and turn zombie when the green bar fills. Survive ten nights to be rescued.

Open `index.html` or play it on the web. It is one HTML file and needs a keyboard and mouse.

## Controls

| Key | What it does |
| --- | --- |
| WASD / arrows | Move |
| Mouse | Aim and fire |
| 1-4 / wheel | Switch weapon |
| R | Reload |
| Hold E | Loot cars, bins and fridges |
| E at the shelter | Buy gear |
| Q | Build mode: click to place or repair, right-click to sell |
| H | Use a medkit |
| F | Zombify, when the green bar is full |
| Enter | Start the night early |
| Esc, M | Pause, mute |
